HG Block — lettering built from the mark

The h and g in the mark aren't typed letters: they're solid blocks with shapes cut out of them. HG Block builds every letter the same way, so the name speaks the mark's language instead of sitting next to it.

→

Straight letters = the h block. Big grip curve top-left, every other corner sharp. Counters are cut as sharp-cornered slots.

→

Round letters = the g block. Soft top corners, big grip curve bottom-right, bottom-left kept sharp. Counters are perfect circles, like the g's button bowl. P and R borrow the same circular bowl.

→

45° notches. The depth runs at 45°, and the notches between the extrusions form the W. W, M, Y and R use the same 45° notch.
